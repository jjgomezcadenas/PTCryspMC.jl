# PTCryspMC.jl
Proton Therapy CRYSP simulations MC (in Julia)
This code:
1) takes data on beta+ emmitters from nuclear fragments produced by a proton beam depositing a certain dose in tissue.
2) Generated gamma pairs from beta+ -beta- annhilations
3) Carries a fast simulation of the response of a PET scanner (CRYSP family or others)
